Theory compact Riemannian submanifolds

$\mathcal{M}$ a compact Riemannian submanifold, metric induced from the ambient one: $\langle\xi,\eta\rangle=\operatorname{tr}(\xi^{\top}\eta)$ on each $T_x\mathcal{M}$.

DP-RFedProj
  1. for $t=0,\dots,T-1$
  2. draw $S_t$, broadcast $\theta_t$
  3. for each $i\in S_t$
  4. for $j=0,\dots,\tau-1$
  5. $\tilde g\gets\operatorname{clip}_C\bigl(P\,\nabla f\bigr)+P\xi$
  6. $\theta\gets\Pi\bigl(\theta-\textsc{Opt}(\tilde g)\bigr)$
  7. send $\Delta^{(i)}=\textsc{Agg.Sub}(\theta_t,\theta^{(i)})$
  8. $\theta_{t+1}\gets\textsc{Agg.Out}\bigl(\theta_t, \tfrac1k\sum_i\Delta^{(i)}\bigr)$
Tools
  • $\Pi$: manifold projection
  • $P_x$: orthogonal tangent projector

    Open problem
    Beat purely local training, when each client holds little data. Accuracy against the amount of training data per client.
    Une carte par clic, puis la variante FedBN. Centralisé: données regroupées, un seul modèle. Fédéré: tronc et tête échangés. Personnalisé: seul le tronc est échangé. Cinquieme clic: sous DP, les modeles n'ont pas de batch norm. Preciser le nombre de sujets par client selon le jeu de donnees. Dernier clic: c'est la vraie question. La federation doit battre l'entrainement local, sinon elle ne sert a rien.
