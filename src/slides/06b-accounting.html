Trade-off function
The server tests $z$ against $z'$. $$\mathcal{T}(P,Q)(\alpha)=\inf_{\phi}\bigl\{\mathbb{E}_Q[1-\phi] \ :\ \mathbb{E}_P[\phi]\le\alpha\bigr\}.$$ (best miss rate at false alarm level $\alpha$)
$f$-DP
$\mathcal{T}\bigl(\mathcal{A}(D),\mathcal{A}(D')\bigr)\ge f$ for every $D\bowtie D'$: no test does better than $f$.
$\mu$-GDP
$f=G_\mu(\alpha)=\Phi\bigl(\Phi^{-1}(1-\alpha)-\mu\bigr)$: $\mathcal{N}(0,1)$ against $\mathcal{N}(\mu,1)$, $\Phi$ the normal cdf.
$\mu$: the gap in units of noise. Larger $\mu$, weaker guarantee.
Trois limites, puis la definition. La figure arrive avec le f-DP. Dire que P est la loi de la sortie quand z est present, Q quand z' le remplace. Le curseur mu montre que grand mu veut dire facile a distinguer.
