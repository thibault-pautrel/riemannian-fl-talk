DP-RFedProj record-level DP Riemannian federated learning

input: $n$ clients, $k$ per round, $\tau$ local steps, batch $B$, $T$ rounds, client optimisers $\textsc{Opt}^{(i)}$, clip $C$, noise $\sigma$
  1. Initialise $\theta_0\in\mathcal{M}$
  2. for $t=0,\dots,T-1$ round
  3. Draw $S_t\subset[n]$, $|S_t|=k$, and broadcast $\theta_t$
  4. for each $i\in S_t$ in parallel
  5. $\theta_{t,0}^{(i)}\gets\theta_t$
  6. for $j=0,\dots,\tau-1$
  7. $\tilde g_{t,j}^{(i)}\gets\frac1B\sum_{\ell} \operatorname{clip}_C\bigl(P\,\nabla f(\theta_{t,j}^{(i)};z_{i,\ell})\bigr) +P\,\xi,\quad \xi\sim\mathcal{N}(0,\sigma^2 I)$
  8. $\bigl(u_{t,j}^{(i)},s\bigr)\gets\textsc{Opt}^{(i)}\bigl(\tilde g_{t,j}^{(i)},s\bigr)$ any optimiser
  9. $\theta_{t,j+1}^{(i)}\gets\Pi\bigl(\theta_{t,j}^{(i)}-u_{t,j}^{(i)}\bigr)$
  10. $\Delta^{(i)}\gets\textsc{Agg.Sub}\bigl(\theta_t,\theta_{t,\tau}^{(i)}\bigr)$, send it see table
  11. $\Delta_t\gets\frac1k\sum_{i\in S_t}\Delta^{(i)}$
  12. $\theta_{t+1}\gets\textsc{Agg.Out}\bigl(\theta_t,\Delta_t\bigr)$
  13. return $\theta_T$
aggregation primitives
Scheme $\textsc{Agg.Sub}(\theta_t,\theta_{t,\tau}^{(i)})$ $\textsc{Agg.Out}(\theta_t,\Delta_t)$
KFAvg $\mathrm{Log}_{\theta_t}\bigl(\theta_{t,\tau}^{(i)}\bigr)$ $\mathrm{Exp}_{\theta_t}(\Delta_t)$
RetAvg $\mathrm{R}^{-1}_{\theta_t}\bigl(\theta_{t,\tau}^{(i)}\bigr)$ $\mathrm{R}_{\theta_t}(\Delta_t)$
ProjAvgours $\theta_{t,\tau}^{(i)}$ $\Pi(\Delta_t)$
RLAvgours $P_{\theta_t}\bigl(\theta_{t,\tau}^{(i)}-\theta_t\bigr)$ $\Pi(\theta_t+\Delta_t)$

Les quatre lignes violettes sont la contribution. Le reste est le squelette fédéré habituel. Dire que l'agrégateur n'entre qu'aux lignes 10 et 12, ce qui donne le template unifié: les deux premières lignes de la table redonnent KFAvg et RetAvg. La privacy couvre les quatre schémas, la vitesse seulement les deux nôtres, parce que leurs primitives sont linéaires en les soumissions.
