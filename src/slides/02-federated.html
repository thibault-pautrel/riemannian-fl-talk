Issue 1: The data is scattered

EEG encodes mental state. It is personal data, so raw trials never leave the site that recorded them.

The centralised pipeline is unavailable, and each site alone has too little data.

Can we train one model on all of it without moving any of it?

Let the crosses appear, then ask the question and pause.

Federated learning

One shared objective,
no shared data
$\displaystyle\arg\min_{\theta}\Bigl\{F(\theta):=\tfrac{1}{N}\sum_{i=1}^{N} F_i(\theta,\mathcal{D}^{(i)})\Bigr\}$
$F_i(\theta,\mathcal{D}^{(i)})=-\dfrac{1}{|\mathcal{D}^{(i)}|} \sum_{\ell=1}^{|\mathcal{D}^{(i)}|}\log\bigl[h_{\theta}(z_{i,\ell})\bigr]_{y_{i,\ell}}$

Initialise $\theta_0$. Then repeat for $T$ communication rounds.

  1. Broadcast
    The server sends $\theta_t$ to a subset $S_t$ of clients.
  2. Local optimisation
    Each selected client runs $E$ epochs on its own data, starting from $\theta_t$.
    $\displaystyle\theta_t^{(i)}\approx\arg\min_{\theta} F_i\bigl(\theta,\mathcal{D}^{(i)}\bigr)$
  3. Upload
    Each client returns $\theta_t^{(i)}$. The data never moves.
  4. Aggregation
    The server forms the next model.
    $\displaystyle\theta_{t+1}\leftarrow\operatorname{Agg} \bigl(\theta_t,\theta_t^{(i)}\bigr)$
