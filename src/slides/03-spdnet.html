A Riemannian architecture for covariance features
Retour au probleme, avec les outils en main.

Where we stand

  1. The features are covariances
    One trial gives $\Sigma\in\mathcal{S}^{++}_C$.
  2. Flattening ignores the constraint
    $\mathrm{vec}(\Sigma)$ or $\mathrm{Vech}(\Sigma)$ drop the positive definiteness.
  3. We now have the tools
    Tangent spaces, metrics, geodesics, retractions.
Idea
Build the classifier as a Riemannian architecture, acting on $\Sigma$ directly.
Rappel court. Les covariances sont les features, elles vivent sur le cone. Les aplatir perd la contrainte. On a maintenant la geometrie, donc on peut construire une architecture qui respecte le cone.

SPDNet: What is optimised?

Layers without learnable parameters
ReEig
spectral rectification, a fixed map
LogEig
tangent space at $I$, a fixed map
Vech
upper triangle of the matrix, a fixed linear map into $\mathbb{R}^{d_L(d_L+1)/2}$
Parametrised layers
BiMap1..L
$X_k = W_k\,X_{k-1}\,W_k^{\top}$
$W_k\in\mathrm{St}(d_{k-1},d_k)$, orthonormal columns. One weight per BiRe block, so $L$ of them.
Fully connected
$\hat{y}=\mathrm{softmax}\bigl(\xi\,\mathrm{Vech}(X_L)+\beta\bigr)$
$\xi\in\mathbb{R}^{K\times d_L(d_L+1)/2}$ and $\beta\in\mathbb{R}^{K}$, free parameters with no constraint.
Consequence
Two optimisers in the same model. Riemannian on Stiefel for the $W_k$, and plain Euclidean for $\xi$ and $\beta$.
